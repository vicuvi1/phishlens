How it works

A five-stage pipeline, all in JavaScript on this page. Nothing in the email is ever opened, rendered as-is or executed.

  1. 1ParseMIME parser built from scratch: encoded headers, multipart, attachments byte-for-byte
  2. 2Sender forensicsSPF · DKIM · DMARC, alignment, Reply-To tricks, look-alike domains, relay hops
  3. 3Links & filesHomographs, hidden destinations, QR codes, macros, HTML smuggling, file-type lies
  4. 4LanguageCredential requests, payment fraud, urgency and threats
  5. 5VerdictRisk score, ATT&CK mapping, IOCs, Markdown / CSV / STIX report

Sender & auth

SPF/DKIM/DMARC results and alignment, display-name spoofing, CEO names on Gmail, Reply-To and Return-Path mismatches, origin IP.

Look-alike domains

Typosquats (paypa1), homoglyphs (micros0ft), Cyrillic homographs (pаypal), brand names in subdomains.

Attachments

Hashes, real type vs extension, double extensions, ISO/LNK/OneNote, VBA macros, remote templates, PDF JavaScript, HTML smuggling.

Quishing

Decodes QR codes inside images and analyses the hidden link, the way attackers dodge link scanners.

SOC-ready output

Defanged IOCs, VirusTotal / urlscan / AbuseIPDB pivots, STIX 2.1 bundle, Markdown incident report, batch triage.

Private by design

No server, no upload, no tracking. Remote images in the preview are blocked and links can't be clicked.
